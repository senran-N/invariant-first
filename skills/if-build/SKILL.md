# 预览与功能开发

未加载时读取 [共同判断](../../RULES.md)。保持当前实现目标，只加载眼前需要的专项。

## ACTION

1. 从需求、真实入口和核心数据选定最直接的完整路径。先解决决定功能能否成立的难点，再完成约定的其余能力。
2. 新项目用现成工具与清楚的小结构；没有真实旧消费者就直接定接口。已有项目沿承担规则的同类入口接入，复用责任而不只复制计算；替换坏局部设计时保留必须成立的语义。
3. 将输入、核心操作、必要副作用和结果接通。补齐直接调用、配置及生成源，让用户从项目真实入口使用功能。
4. 运行目标用例并据反馈修正，同步必要用法。外部环境不可用时只在真实边界使用明确替身，并区分其结果与实际集成。

## DONE

约定功能在目标范围完整可用，调用与说明一致。核心尚未接通就继续实现；外部阻塞则交付可用部分并说明缺口。完成当前范围后按用户请求衔接，不自动扩展产品路线图。
