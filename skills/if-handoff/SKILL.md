# 跨会话接续

未加载时读取 [共同判断](../../RULES.md)。恢复完成后继续原 PRIMARY；主要交付物是接手分析时才以 frame 为主。

## 恢复时 ACTION

从已有入口和任务记录定位当前目标、硬约束、完成状态与下一动作。记录是通往事实的索引；观察属于哪个版本、环境和对象，以实际来源为准，不从摘要的缺失推断能力不存在。

沿支撑下一步的关键前提核对差异：前提未变，复用已确认的入口、决定和命令；相关前提变化，只重新读取受影响位置。会话间出现的人工编辑、远端变更或其他执行者结果都是新的仓库事实，不是要被旧摘要纠正的噪音。一次局部变化不让所有旧结论失效，也不能用旧结论覆盖新事实。

有其他执行者时确认当前写入归属；用已支持的协作方式隔离工作，否则串行推进。接续材料不产生新的操作授权。

## 暂停时 ACTION

仅在确需接续时更新项目已有位置，留下目标与边界、实际完成和未完成、关键决定所依赖的代码或条件、最近反馈与具体下一动作。稳定知识回到正式责任位置，临时记录只引用；不保存私有思维过程、秘密或整段工具输出。

## DONE

下一位能从真实文件继续完成原目标。可在本轮完成的工作继续做，交接不是提前结束的理由。

依据：[机制归纳](../../references/ai-coding-pain-points.md)；不要求宿主具有专用记忆或后台执行能力。
