# 重构、迁移与转向

未加载时读取 [共同判断](../../RULES.md)。围绕已授权的变化完成切换，外部承诺与内部实现分别处理。

## ACTION

1. 明确变化的对象：结构编辑移动原内容并更新必要引用；重构保持约定行为；迁移保持需要的数据含义；转向改变已授权的目标。结构调整不自动包含语义重写。
2. 读清表示承载的语义及其保证位置，再判断什么冗余。理由不明时查相关定义、用例或局部历史；同一语义即使换了领域名称仍应保留。
3. 在有责任的边界实现新路径。足以决定方案的未知先用最小实现消除，确定的局部调整直接做；方向尚未确定且用户只要设计时交给 frame。
4. 让新路径接管真实调用。无历史依赖时直接替换；有消费者或数据时使用 contracts/state 的适用方法。过渡期间读写主次、事实来源、失败恢复与退出条件清楚，代码回退不等于数据恢复。
5. 改完直接调用、配置、生成源、测试与用法。用针对性反馈确认保留的语义和预期变化；删除已无责任的旧路径，保留有真实消费者的过渡。

## DONE

本次替换增量闭合，新路径承担目标范围的工作。长期迁移可以分次，但本次调用不能悬空；剩余过渡有明确责任，下一位能据仓库继续完成。
